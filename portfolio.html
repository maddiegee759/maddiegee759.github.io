Portfolio


InTheSea - Dating Website

A full stack dating website developed as part of a four-person team. Built a responsive frontend and Flask backend, with integration of the StarLoveMatch API. This project demonstrates use of external APIs, server-side development and collaborative software development.

Flight Path Optimisation using Dijkstra's Algorithm

A C program that models flight routes as a graph and uses Dijkstra's algorithm to determine the most efficient path between destinations. This project demonstrates practical application of graph theory, algorithm design and computational efficiency.

Indago - Motivational Study App

High-fidelity prototype for a motivational, study app aimed at older students. Used evidence-based methods of gamification, including point systems, badges, and progress tracking to encourage user engagement. Atomic design was a consistent priority during the design process shown through the use of reusable components and a consistent styling.

Games Like Wordle

A simple website providing a single, convenient place to access a collection of browser-based games. Designed and developed an accessible interface and deployed the project as a live website for personal use and sharing.
